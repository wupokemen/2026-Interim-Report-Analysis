腾讯2026年中报：
AI烧掉了现金，但腾讯还是一家好公司吗？

主营业务持续增长，AI资本开支急剧上升。本文从商业模式、资本配置、财务质量与长期现金流出发，讨论腾讯正在经历的投资逻辑变化。

核心投资观点

腾讯从“高护城河、低资本开支的互联网超级现金牛”，走向“以高AI资本开支换取未来增长空间的科技公司”。关键不在投入规模，而在投入能否带来超额现金流。

引言

2026年8月12日，腾讯控股（00700.HK）公布2026年中期业绩。

这份财报有点意思。

上半年营收4012亿元，同比增长10%；毛利润2297亿元，同比增长12%；经营利润1347亿元，同比增长14%。但到了二季度，归母净利润仅增长0.7%，资本开支却同比暴增176%，达到528亿元，二季度自由现金流甚至转为负数。

一边是主营业务继续增长，一边是AI投入疯狂烧钱。

很多人看到“利润增速大幅放缓”“自由现金流转负”，第一反应可能是：

腾讯的好日子是不是到头了？

但如果我们不看股价，只看资产负债表和利润表，再回到巴菲特那句话：

“买股票就是买公司。”

那么，腾讯究竟是一家怎样的公司？

一、商业模式

腾讯是一家什么公司？

如果只说“互联网公司”，其实太简单了。

我更愿意把腾讯理解为一家以微信生态为核心、同时拥有游戏、广告、支付、云服务和投资组合的超级现金流企业。

微信是腾讯最大的流量入口。

用户进入微信以后，可以使用聊天、朋友圈、视频号、小程序、公众号、微信支付、小游戏、企业微信等大量服务。

然后腾讯通过广告、游戏、支付、金融科技、企业服务等方式，把流量变成收入。

这套商业模式最可怕的地方并不是某一个产品有多赚钱，而是：

腾讯拥有一套极其庞大的用户基础设施。

2026年上半年，腾讯增值服务收入1945亿元，同比增长6%；营销服务收入817亿元，同比增长21%；金融科技及企业服务收入1202亿元，同比增长9%。

其中最值得关注的是广告业务。

2026年二季度，腾讯营销服务收入436亿元，同比增长22%。

为什么广告业务增长这么快？

一个重要原因就是AI。

腾讯正在利用AI优化广告推荐、自动投放和广告素材生成，提高广告转化效率。

这意味着AI并不是完全没有商业化。

至少在广告业务里，AI已经开始直接提高腾讯原有业务的赚钱能力。

游戏依然是腾讯最大的现金牛。

2026年二季度，增值服务收入984亿元，同比增长8%，其中国内游戏收入473亿元，同比增长17%。

《王者荣耀》、无畏契约、三角洲行动等产品继续贡献收入。

游戏最大的优势是：

研发一次，全球销售；用户规模越大，边际成本越低。

这也是为什么腾讯即使已经是一家体量巨大的公司，仍然能够保持非常高的利润率。

所以从商业模式来看：

微信是流量入口，游戏和广告是利润中心，支付和企业服务负责变现，投资组合则提供额外的资产价值。

这套商业模式目前依然非常优秀。

但问题来了。

二、腾讯最大的变化：AI

如果说过去十年的腾讯核心逻辑是：

微信 + 游戏 + 广告 + 金融科技

那么未来十年的腾讯，必须再加上一个：

AI。

问题是，AI不是一个轻资产生意。

过去腾讯的商业模式非常舒服。

用户增长以后，不需要投入太多固定资产，就可以获得大量现金流。

但AI时代完全不同。

你想训练大模型，就需要GPU。

想让用户使用AI，就需要大量算力。

想提供AI Agent，就需要持续购买计算资源。

所以腾讯正在从一家“轻资产互联网公司”，越来越像一家需要持续建设基础设施的科技公司。

AI资本开支重点

2026年上半年，腾讯资本开支达到847亿元，同比增长约82%。其中二季度资本开支528亿元，同比增长176%。

AI基础设施投入→短期自由现金流下降→未来AI现金流回报

这是一个非常夸张的数字。

更值得注意的是，腾讯二季度自由现金流已经变成负138亿元。

这在过去的腾讯身上并不常见。

为什么？

因为腾讯正在把原本可以拿来回购股票、分红或者投资其他公司的现金，投入AI基础设施。

简单来说：

以前腾讯赚100块，可以拿60块甚至更多给股东；现在腾讯赚100块，可能先拿出去买GPU、建数据中心、购买算力。

这对于股东到底是好事还是坏事？

关键不在于AI投入有多大。

而在于：

这些投入未来能够产生多少现金流。

如果腾讯今天投入1000亿元AI资本开支，未来能够创造3000亿元、5000亿元甚至更多现金流，那么今天的“烧钱”其实是在创造价值。

但如果AI最终只是一个巨大的成本中心，那么腾讯今天的高资本开支就会侵蚀未来的股东回报。

所以我认为：

2026年是腾讯投资逻辑发生变化的一年。

过去我们主要观察腾讯的利润增长。

未来几年，更应该观察：

腾讯投入AI的钱，到底能不能赚回来。

三、企业文化与资本配置

巴菲特曾经说过：

“对于一家企业来说，管理层的资本配置能力非常重要。”

如果一家企业赚到的钱不知道怎么花，那么再好的商业模式也可能被糟糕的资本配置毁掉。

腾讯过去十几年的资本配置能力，其实是比较优秀的。

腾讯一方面持续投资游戏、微信生态和云服务；另一方面通过投资大量优秀互联网公司，形成了庞大的投资组合。

截至2026年上半年，腾讯持有的上市被投公司股权公允价值约4872亿元，未上市被投公司账面价值约3879亿元。

当然，这些资产不能简单全部加到腾讯市值上。

但它们确实构成了腾讯非常厚的安全垫。

更重要的是，腾讯近年来持续回购股票和提高股东回报。

这意味着腾讯管理层并没有忘记股东。

但2026年出现了一个新的问题：

AI。

以前腾讯最大的资本配置问题是：

“赚到的钱应该投资还是回购？”

现在变成了：

“到底应该投入多少AI？”

我认为腾讯目前最大的风险，并不是微信被竞争对手替代，也不是游戏业务突然崩塌。

而是：

管理层会不会因为AI浪潮，而进行过度投资。

AI是一个非常容易让企业管理层失去理性的领域。

因为所有人都害怕错过下一次技术革命。

但对于股东而言，最重要的问题永远不是：

“腾讯有没有AI？”

而是：

“腾讯在AI上投入1块钱，未来能不能创造超过1块钱的价值？”

这才是资本配置的本质。

先看利润表。

从利润表来看，腾讯的主营业务依然非常健康。

收入增长10%，但毛利润增长12%，营业利润增长14%。

也就是说：

腾讯不是靠牺牲利润率换增长，反而还在产生经营杠杆。

这一点非常重要。

再看资产负债表。

这里出现了一个非常值得注意的变化：

腾讯的净现金明显下降。

但这并不意味着腾讯财务状况恶化。

恰恰相反，腾讯依然拥有非常强的资产负债表。

它的问题是：

过去赚钱以后现金不断增加，现在开始主动把现金投入AI。

固定资产也从2025年末的约1499亿元增加到2026年中的约1989亿元。

半年增加约490亿元。

这些钱最终都变成了数据中心、服务器等基础设施。

所以如果只看资产负债表，很容易误以为腾讯“负债增加、现金减少”。

但如果把它和资本开支放在一起看，会发现背后的逻辑其实非常清楚：

腾讯正在用自己的资产负债表，为AI时代下注。

这是一场主动选择，而不是被迫融资。

五、腾讯现在还是一家“现金牛”吗？

这是我最关心的问题。

因为买股票最终买的是未来能够属于股东的现金流。

2026年第一季度，腾讯自由现金流仍然达到567亿元。

但第二季度由于资本开支暴增，自由现金流下降至负138亿元。

如果把2026年上半年放在一起看，腾讯依然产生了大量经营现金流，但AI资本开支已经开始吞噬过去非常充裕的自由现金流。

所以我不会因为腾讯二季度自由现金流转负，就直接得出：

“腾讯现金流恶化。”

更准确的说法应该是：

腾讯正在主动把今天的自由现金流，换成未来的AI基础设施。

这就像一家拥有稳定现金流的企业，突然决定大规模建设新的工厂。

短期自由现金流一定会下降。

真正需要判断的是：

新工厂未来能不能带来足够高的回报。

腾讯现在也是一样。

所以未来2—3年，我认为腾讯最重要的财务指标已经不是单纯的净利润，而是：

资本开支 / 自由现金流 / AI收入增长 / AI业务毛利率。

如果未来出现：

资本开支下降 + AI收入快速增长 + 自由现金流重新增长，
那么现在的AI投入就是成功的。

反过来，如果：

资本开支持续暴增 + AI收入增长缓慢 + 自由现金流持续为负，
那就意味着腾讯可能高估了AI的商业价值。

六、腾讯最大的护城河是什么？

很多人说腾讯的护城河是微信。

我认为对，但还不够完整。

腾讯真正的护城河是：

微信生态 + 用户规模 + 内容生态 + 支付体系 + 游戏研发能力 + 广告系统 + 资本配置能力。

微信本身可能是最重要的一环。

但微信真正厉害的地方，并不是“聊天”。

而是：

它已经成为中国互联网最重要的基础设施之一。

你可以在微信里聊天、支付、购物、看视频、刷公众号、使用小程序、打游戏、办公。

这意味着竞争对手即使拥有一个更好的单点产品，也很难把腾讯整个生态复制出来。

所以腾讯和很多互联网公司最大的不同是：

它不是一个产品，而是一套生态系统。

生态系统最大的优势，就是用户迁移成本非常高。

七、增长预估与估值

如果未来腾讯的传统业务仍然保持8%—10%左右的增长，同时AI开始逐渐商业化，那么我认为腾讯未来几年仍然可以维持中高个位数到两位数的利润增长。

但这里有一个很大的变量：

AI资本开支。

如果未来AI资本开支继续维持2026年的高增长，那么即使收入增长，股东最终拿到的自由现金流也可能增长缓慢。

因此，我不会简单给腾讯一个20倍、25倍PE，然后得出目标价。

腾讯更适合采用：

“传统业务估值 + AI期权价值 + 投资组合价值 - 净负债”

的方法。

假设传统业务未来保持8%—10%的利润增长，长期自由现金流增速逐渐下降到3%—5%，那么腾讯成熟业务本身就已经是一项非常优质的资产。

而AI则相当于额外的“期权”。

现在的问题不是腾讯有没有AI价值，而是：

市场已经为腾讯的AI价值支付了多少钱。

截至2026年8月12日前后的市场价格，腾讯股价约在430—460港元区间波动，市值约4万亿港元，对应市场已经给予腾讯一个不低但也谈不上疯狂的估值。

因此，我目前更倾向于把目前的腾讯定义为：

“合理价格买入优秀公司，而不是明显低估的烟蒂股。”

如果未来股价因为AI资本开支担忧而出现较大回调，而公司的游戏、广告、微信生态依然保持增长，那么反而值得重点关注。

因为市场最容易犯的错误就是：

把短期自由现金流下降，误认为企业长期价值下降。

八、结论

看完腾讯2026年中报，我的结论发生了一个变化。

以前我认为腾讯是一家：

高护城河 + 高利润 + 高现金流 + 低资本开支
的互联网超级现金牛。

现在腾讯正在变成：

高护城河 + 高利润 + 高现金流基础 + 高AI资本开支
的科技公司。

这意味着腾讯的确定性下降了一点，但想象空间增加了。

游戏还在赚钱。

广告还在增长。

微信生态依然牢不可破。

金融科技依然稳定。

真正发生变化的是：

腾讯开始把大量今天的利润和现金流，下注于明天的AI。

所以我不会因为二季度净利润只增长0.7%，就认为腾讯不行了。

恰恰相反，我认为现在最值得研究的问题是：

腾讯到底能不能把AI变成下一台“印钞机”？

如果能，那么今天的AI资本开支可能是未来十年腾讯最重要的一次资本投入。

如果不能，那么腾讯过去优秀的自由现金流能力就会被AI资本开支逐渐侵蚀。

所以对于腾讯，我现在最关注的不是PE，也不是股价短期涨跌，而是三个数字：

  1. AI资本开支什么时候见顶？
  2. AI收入什么时候真正开始放量？
  3. 自由现金流什么时候重新恢复高速增长？

这三个问题的答案，将决定腾讯未来十年的投资回报。

买股票就是买公司。

对于今天的腾讯来说，真正需要买的不是过去那个“微信+游戏”的腾讯，而是：

一家能不能把AI做成第二增长曲线的腾讯。
